cp · COPY · mv · MOVE · rm · DEL · * · ? · seguridad en la eliminación

Copiar, mover y eliminar archivos son operaciones fundamentales. La habilidad crítica es hacer esto de forma segura en ambientes producción sin perder datos.

Propósito técnico de la sesión

¿Qué dominaremos hoy?

  • Copiar archivos completos respetando permisos y estructuras con cp (Linux) y COPY (Windows).
  • Mover y renombrar archivos atomicamente usando mv (Linux) y MOVE (Windows), evitando duplicados.
  • Eliminar archivos con seguridad usando banderas interactivas (-i, /Y, /-Y).
  • Usar comodines (*, ?) para operar sobre múltiples archivos sin escribir cada nombre.

⚠️ Advertencia técnica:

En terminal, NO hay papelera de reciclaje. Cuando eliminas, el archivo desaparece. Siempre usa -i (interactive) en operaciones críticas.

Bloque C · Manipulación de Archivos

cp (Linux) / COPY (Windows): Duplicar archivos

Aspecto Linux / Bash Windows CMD / PowerShell
Sintaxis básica cp origen destino COPY origen destino
Copiar recursivo (directorios) cp -r dir1/ dir2/ COPY dir1\* dir2\ /S
Interactivo (preguntar si existe) cp -i archivo1 archivo2 COPY /Y archivo (sobrescribe)
Preservar permisos cp -p archivo1 archivo2 Automático en NTFS

Ejemplo práctico: Hacer backup de archivo crítico antes de editar:

$ cp -i /etc/passwd /etc/passwd.bak cp: overwrite '/etc/passwd.bak'? y $
La flag -i previene sobrescrituras accidentales 3 / 8
Bloque C · Manipulación de Archivos

mv (Linux) / MOVE (Windows): Mover y renombrar atómicamente

Operación Linux Windows
Renombrar mv viejo.txt nuevo.txt REN viejo.txt nuevo.txt
Mover a directorio mv archivo.txt /home/backup/ MOVE archivo.txt C:\backup\
Mover y renombrar mv archivo.txt /home/copia/nuevo.txt MOVE archivo.txt C:\copia\nuevo.txt
Interactivo mv -i archivo /destino/ MOVE /-Y archivo destino

Ventaja técnica de mv: No duplica datos en disco. Con COPY + DEL, temporalmente usas el doble de espacio.

Caso real: En servidores con disco casi lleno, mv es seguro; cp puede fallar.

mv es más eficiente que cp + rm 4 / 8
Bloque C · Manipulación de Archivos

rm (Linux) / DEL (Windows): Eliminar archivos (con cuidado)

Operación Linux Windows
Eliminar un archivo rm archivo.txt DEL archivo.txt
Eliminar con confirmación rm -i archivo.txt DEL /-Y archivo.txt
Forzar (sin preguntar) rm -f archivo.txt DEL /F archivo.txt
Eliminar recursivo (directorio) rm -r directorio/ DEL /S C:\directorio\*.*
⚠️ PELIGRO EXTREMO: rm -rf / o rm -rf /\* en Linux borra TODO desde raíz. No existe "deshacer".

Recomendación: Siempre usa rm -i en scripts; prueba primero con ls o find para estar seguro.

En terminal: una eliminación es para siempre 5 / 8
Bloque D · Patrones y Comodines

Comodines (Wildcards): * y ? para múltiples archivos

Asterisco *

Representa: Cero o más caracteres

*.txt Coincide: archivo.txt nota.txt a.txt *.log Coincide: error.log debug.log app.log

Signo de interrogación ?

Representa: Exactamente 1 carácter

file?.txt Coincide: file1.txt file2.txt fileA.txt NO: file12.txt ????.doc Coincide: nota.doc test.doc NO: archivo.doc

Combinados

Poder: Filtrar exactamente lo que necesitas

backup_*.tar.gz Coincide: backup_001.tar.gz backup_2024.tar.gz doc?.txt Coincide: doc1.txt docA.txt NO: document.txt
Los comodines se expanden antes de ejecutar el comando 6 / 8
Práctica Guiada 3

Escenario: Reorganizar un directorio de proyectos

Contexto: Tienes un directorio /home/user/proyectos con archivos desordenados. Necesitas:

  1. Crear un backup de todos los archivos .py en backup/ sin sobrescribir si ya existe.
  2. Renombrar todos los archivos document_?.txt a doc_?.bak para archivar.
  3. Verificar cuántos archivos *.log hay y eliminarlos con confirmación.

Instrucción: Escribe los comandos exactos en Bash y luego en PowerShell. Piensa en qué flags de seguridad deberías usar.

Restricción: No uses rm -f ni DEL /F sin confirmación previa.
Tiempo: 5 minutos · En parejas o individual 7 / 8
Solución Práctica 3

Reorganización segura del directorio

# BASH / LINUX # 1. Backup de .py sin sobrescribir $ mkdir -p backup $ cp -i *.py backup/ cp: overwrite 'backup/script.py'? n # rechazamos si existe # 2. Renombrar document_?.txt → doc_?.bak $ for f in document_?.txt; do mv "$f" "${f//document_/doc_}.bak" done # Resultado: document_1.txt → doc_1.bak # 3. Contar y eliminar *.log con seguridad $ ls *.log | wc -l # Contar $ rm -i *.log rm: remove 'error.log'? y rm: remove 'debug.log'? y $
# POWERSHELL / WINDOWS (alternativa) # 1. Backup de .py PS> New-Item -ItemType Directory -Path backup -ErrorAction SilentlyContinue PS> Copy-Item *.py backup/ -Confirm # 2. Renombrar PS> Get-ChildItem document_?.txt | Rename-Item -NewName {$_.Name -replace 'document_','doc_'} # 3. Listar y eliminar con confirmación PS> Get-ChildItem *.log | Measure-Object | Select-Object -ExpandProperty Count PS> Get-ChildItem *.log | Remove-Item -Confirm

Lecciones clave:

  • Siempre usa -i (interactive) o -Confirm antes de rm o eliminar.
  • Usa ls o Get-ChildItem primero para verificar qué coincide con tu patrón.
  • cp -i es tu aliado; rm -f es tu enemigo.
